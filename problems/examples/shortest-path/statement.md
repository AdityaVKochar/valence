A directed graph has $n$ vertices and $m$ weighted edges. Find the length of the shortest path from vertex $1$ to vertex $n$.

## Input

The first line contains $n$ and $m$ ($2 \le n \le 1000$, $0 \le m \le 5000$). Each of the next $m$ lines contains $u$, $v$ and $w$: an edge from $u$ to $v$ with weight $w$ ($1 \le u, v \le n$, $1 \le w \le 10^6$).

## Output

Print the length of the shortest path, or $-1$ if vertex $n$ cannot be reached.
