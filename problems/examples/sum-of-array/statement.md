Given an array of $n$ integers, print their sum.

## Input

The first line contains $n$ ($1 \le n \le 2 \cdot 10^5$). The second line contains $n$ integers $a_1, \ldots, a_n$ ($-10^9 \le a_i \le 10^9$).

## Output

Print the sum of the array.

## Notes

The sum does not fit in a 32-bit integer. Reading $2 \cdot 10^5$ numbers quickly matters in some languages.
